# Integrated Retail Sales Performance Tracking and Analysis

## Project Context In the competitive retail industry, businesses struggle with fragmented data and delayed decision-making. This project was developed for a mid-sized retail chain to automate data integration and provide real-time visibility into business performance.

## Project Objectives

Data Integration: Unify disparate transactional data into a single source of truth.

Predictive Insights: Forecast future sales trends and segment customers based on purchasing behavior.

Interactive Visualization: Create modern dashboards to track regional performance and demographics.

## Tools & Environment

Python: Data cleaning (Pandas) and Machine Learning (Scikit-learn).

Power BI / Tableau: Dashboard creation and KPI tracking.

GitHub: Version control and project hosting.
