# Retail Sales Performance Dashboard

This directory contains the interactive visualization component of the project, built using **Power BI Desktop**.

## Files
* **Retail_Analysis_Final.pbix**: The primary Power BI source file.

## Visualizations Included
1. **Sales Trend Analysis**: A line chart showing monthly revenue to identify seasonal patterns (e.g., the August peak).
2. **Product Performance**: A bar chart comparing total sales across Electronics, Clothing, Beauty, and Home Decor.
3. **Customer Demographics**: A pie chart breaking down sales by Age Group (e.g., 26-35, 36-50).
4. **Customer Segmentation**: A scatter plot visualizing the K-Means clusters (Segments 0, 1, and 2) generated by the Python script.

## Interactivity
* Use the **Product Category Slicer** on the left to filter all charts by specific departments.
* Cross-filtering is enabled; clicking a segment in the bar chart will update the trend line and demographics automatically.
